# FormFit AI — Impact Evaluation

## Status: PENDING — no real user evaluation has been conducted

No CrossFit users have used FormFit AI as of this document's creation (2026-10-25). **No participants, feedback, scores, or improvement percentages are reported here or anywhere else in this project.** This document defines the protocol and feedback form so a real evaluation can be run and incorporated later; it is not itself evidence of impact.

## Evaluation Protocol

### Participants
Real CrossFit athletes (any experience level), recruited voluntarily. Minimum meaningful sample: not prescribed here — even 1 real, honestly reported participant is more valuable than any number of fabricated ones.

### Procedure
1. Participant is given a sample WOD (typed or a real whiteboard photo) and asked to manually produce their own warm-up, scaling plan, and complementary exercises, **timed**.
2. Participant then uses FormFit AI with the same WOD, **timed** from WOD entry to receiving a coaching plan.
3. Participant completes the feedback form below.
4. Record raw timing and raw responses verbatim — no averaging or interpretation beyond simple descriptive reporting (e.g., "participant 1 took 6 minutes manually, 45 seconds with FormFit AI") until a real sample exists.

### Metrics
- **Time required**: manual interpretation/personalization time vs. FormFit AI time (raw seconds/minutes per participant, not an invented average).
- **Perceived usefulness**: participant's own 1–5 rating + free text.
- **Clarity and accuracy of recommendations**: participant's own assessment, specifically asked to flag any recommendation that seemed wrong, unsafe, or confusing.
- **Problems encountered**: open-ended, verbatim.
- **Would use again**: yes/no + why.

## Reporting Rules for When Real Data Exists
- Report exact participant count (even if it is 1).
- Report raw per-participant numbers, not just an aggregate, unless the sample is large enough that aggregation is meaningful and the raw data is also retained.
- Never compute or state a percentage improvement without showing the underlying raw numbers it was computed from.
- If a participant reports a problem or unsafe output, report it verbatim in the final report's Limits & Next Steps section — do not omit negative feedback.
